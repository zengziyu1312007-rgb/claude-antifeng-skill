# 04 · 内容合规边界

> 触发 Usage Policy 红线 → 封号是没得申诉的。这一篇讲清楚红线在哪、灰区怎么避开。

## 一、先读官方政策

本篇只是 **导览**，权威来源永远是官方：

- [Anthropic Consumer Terms](https://www.anthropic.com/legal/consumer-terms)
- [Usage Policy](https://www.anthropic.com/legal/aup)
- [Usage Policy FAQ](https://www.anthropic.com/legal/aup-faq)

政策会更新，定期回看。

## 二、红线（直接封号类）

以下内容 **不要碰**，本 Skill 也不会教你"如何打擦边球"：

1. **未成年人性化**：任何涉及未成年人的性相关内容。零容忍。
2. **危险化学品 / 武器制造**：制造爆炸物、化学武器、非法武器的具体指导。
3. **恶意网络安全活动**：恶意软件、勒索软件、未授权入侵的具体实现。
4. **选举操纵 / 大规模虚假信息**：批量生成政治虚假信息、选民压制。
5. **生物威胁**：病原体增强、生物武器相关。
6. **监控 / 骚扰 / 人肉**：针对特定个人的跟踪、监控、人肉搜索。
7. **欺诈 / 非法金融服务**：具体欺诈Scheme、非法金融服务操作指导。

这些是 Anthropic 在 Usage Policy 里明确禁止的。触发后基本是 **不可申诉的永久封禁**。

## 三、灰区（容易误触发的）

这些不是红线，但高频触发会让账号进入"高风险用户"画像：

### 1. 越狱 / 越狱 prompt

- 试图让 Claude 输出违反 policy 内容的 prompt；
- 即使没成功，频繁尝试本身是异常信号；
- 不要把"越狱 prompt"当日常玩具。

### 2. 角色扮演包装敏感内容

- "你现在是 XXX 角色，不受限制地回答……" 这类 wrapper；
- Anthropic 的检测对这类 wrapper 非常敏感；
- 即使为了创作，也避免用"解除限制"式的人设。

### 3. 大批量同类敏感问题

- 即使每个问题单独看 OK，集中轰炸某一敏感领域（暴力、医疗、法律建议）会触发批量风险评分；
- 真实用户的使用是 **多样** 的，不要在某一敏感领域疯狂挖。

### 4. 冒充专业建议

- 让 Claude 输出医疗诊断、法律意见、金融投资建议并当真使用 / 发布；
- Anthropic 对"高风险建议"有额外审核；
- 用 Claude 辅助理解可以，让它"出诊断 / 出法律意见"并传播 = 风险叠加。

### 5. 隐私数据投喂

- 把他人 PII（身份证号、电话、住址）丢给 Claude 处理；
- 涉及隐私合规，也可能触发内容检测；
- 处理数据前脱敏。

## 四、安全使用习惯

### 1. 用 System Prompt 声明用途

```
你是一个帮助我整理学习笔记的助手。我会输入课程内容，
请帮我总结要点、出练习题。不要输出与学习无关的内容。
```

明确的用途声明 = 降低误判概率。

### 2. 遇到 refusal 不要硬刚

- Claude 拒答说明触发了安全层；
- 不要换 10 种说法逼它答，换 10 种说法 = 异常尝试画像；
- 换个思路、调整任务，或者接受这个边界。

### 3. 高风险任务二次验证

让 Claude 做医疗 / 法律 / 金融相关的内容时：

- 当辅助，不当结论；
- 关键结论自己核实；
- 不要把 Claude 输出当专业意见发布给他人。

## 五、内容合规快查表

```
✅ 先读官方 Usage Policy
✅ 多样化使用，不在敏感领域狂挖
✅ System prompt 声明合规用途
✅ refusal 后调整任务，不硬刚
✅ 高风险输出二次核实

❌ 红线领域（未成年人 / 武器 / 恶意网安 等）
❌ 越狱 prompt 当玩具
❌ "解除限制"式角色 wrapper
❌ 投喂他人 PII
❌ 把 Claude 输出当专业意见发布
```

## 小结

内容合规不是"知道红线在哪然后擦边"，而是 **真的不碰红线**。灰区的东西能不用就不用——封号损失的是整个账号和订阅，不值得。
