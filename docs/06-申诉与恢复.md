# 06 · 申诉与恢复

> 自查做完、确认不是使用习惯问题，或账号已被封禁，走这篇。**只走官方渠道**，别信"代解封"。

## 一、官方申诉渠道（按优先级）

### 1. 网页端申诉入口

- claude.ai 登录页 / 页面顶部的提示里，通常有 "Contact us" / "Appeal" 链接；
- 封禁页面有时直接带申诉表单入口；
- 这是最直接的渠道，优先用。

### 2. 邮件申诉

发送到 Anthropic 官方支持邮箱（以官网 [anthropic.com/legal](https://www.anthropic.com/legal) 公示的 contact 为准，不要用来源不明的邮箱）。

邮件要素见第三节模板。

### 3. Console Support

- [console.anthropic.com](https://console.anthropic.com) → Help / Support；
- API 用户优先走这里，能关联到 organization 与用量。

### 4. 社交渠道（仅辅助）

- Anthropic 官方 Twitter/X / LinkedIn 公开号；
- **不要** 在公开社交平台贴账号邮箱、订阅号等敏感信息；
- 仅用于"引导对方去看你的官方申诉"，不要当主渠道。

## 二、申诉前的准备

申诉前先准备好以下材料，**一次给齐**（来回补料会拖慢处理）：

1. **注册邮箱**（用于定位账号）；
2. **注册时使用的姓名**（与证件一致）；
3. **订阅档位与最近一次扣款时间**；
4. **异常发生的大致时间**；
5. **异常的具体表现**（截图最好）；
6. **你已做的自查与修复动作**（证明你是认真用户，不是碰瓷）；
7. **使用场景说明**（你在用 Claude 做什么，证明是正常用途）。

## 三、申诉邮件模板


## 四、申诉注意事项

### 1. 一次说清

- 邮件把自查结果、使用场景、材料一次给齐；
- 客服来回邮件成本高，补料一轮拖几天。

### 2. 诚实

- 别编故事。Anthropic 后台有完整的使用 / 网络 / 支付记录；
- 你说"没用过代理"但后台 IP 一天跳三国，直接信用破产。

### 3. 别情绪化

- 别威胁、别说"我要去投诉你们"、"我要发推特曝光"；
- 客服有裁量空间，态度好不加分，态度差一定减分。

### 4. 别群发 / 多开 ticket

- 一个渠道一个 ticket 就够了；
- 同时开 5 个 ticket = 系统判你 spam，全合并到最末尾。

### 5. 耐心

- 工单处理通常 1–5 个工作日；
- 期间不要疯狂催，催一次就会重置排队位置的概率很高。

## 五、关于"代解封"

网上有声称"付费代解封 Claude 账号"的服务。建议：

- **不要用**。代解封通常靠的就是本 Skill 明确反对的手段（伪造材料、批量申诉、内部关系话术），一旦被识破，账号永久封禁且申诉通道关闭；
- 把你的注册邮箱、身份信息、支付信息交给陌生第三方 = 二次风险；
- 真被封且官方申诉无效，损失一个订阅比把身份信息泄露给黑产划算。

## 六、封禁后的善后

如果最终确认不可恢复：

1. 取消订阅（避免持续扣款）；
2. 撤销该账号下所有 API key；
3. 解绑第三方集成（Zapier、Make 等）；
4. 备份该账号里需要保留的对话 / 项目；
5. 如需继续使用，**用新的真实身份合规注册新账号**——不要复用旧账号的身份 / 支付 / 设备画像（否则新账号会被关联判定）。

## 小结

申诉只有官方渠道一条路。把材料备齐、诚实陈述、耐心等。封了就封了，比把身份信息送给"代解封"黑产安全得多。
