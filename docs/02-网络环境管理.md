# 02 · 网络环境管理

> 风控系统里有一半权重在看"网络环境是否像一个正常用户"。这一篇是防风的硬核。

## 一、核心原则：稳定 > 一切

风控对网络的判断，不是"你在哪个国家"，而是 **你的网络画像稳不稳**。

判定"正常用户"的标准是：

- 同一个账号，登录 IP 在一段时间内有 **清晰的归属地规律**；
- 设备指纹相对稳定，不会一天换三个设备；
- 网络环境的 ASN（自治系统）不频繁跳变。

判定"异常"的标准是：

- IP 今天美国、明天日本、后天德国；
- 同一账号在 10 分钟内出现两个不同半球的登录；
- 用数据中心 IP（云厂商 IP 段）直接访问 claude.ai。

## 二、IP 管理

### 1. 用住宅 IP，不要用数据中心 IP

| IP 类型 | 风控风险 | 说明 |
|---------|---------|------|
| 家庭宽带 IP（住宅） | 低 | 真实用户画像 |
| 移动 4G/5G IP | 低-中 | 真实但会跳动，注意稳定性 |
| 商业宽带 / 办公 IP | 中 | 可用，但需稳定 |
| 云厂商 IP（AWS/GCP/Azure 等） | 高 | 数据中心段，强风控信号 |
| 免费/共享代理 | 极高 | IP 被大量人共用，已被标记 |

**结论**：优先用自家宽带 / 移动网络出口。如果你需要访问 Anthropic 服务，使用 **稳定** 的网络出口，而不是到处乱跳的免费代理。

### 2. IP 要"有归属"，不要"到处跳"

即使你因为地区原因需要走代理，也遵循：

- **固定一个出口节点 / 一个地区**，长期使用，不要每天换国家；
- 出口 IP 越稳定，账号网络画像越清晰；
- 不要在不同节点之间来回切换登录同一个账号。

### 3. 避免 IP 共享

- 大量人共用的代理 IP（尤其免费代理），几乎都被打上"共享 / 滥用"标签；
- 用这类 IP 登录 Claude，等于在账号上盖一个"高风险环境"戳。

## 三、设备指纹

### 1. 设备要稳定

- 同一账号长期在 **1–2 台设备** 上使用最理想；
- 不要在网吧、公共电脑、他人设备上登录自己账号；
- 多设备并发登录（同时在线 3+ 设备）也是异常信号。

### 2. 浏览器环境

- 用固定的浏览器，不要每次换一个；
- 不要用"指纹浏览器"刻意伪装——这类工具的特征反而会被反作弊系统识别；
- 正常浏览器 + 正常 cookie + 正常登录态 = 最稳。

### 3. 登录态保持

- 不要频繁登出再登入。登录态保持是"正常用户"特征；
- 不要在不同设备间频繁复制 cookie / session（这是账号共享的典型动作）。

## 四、API 用户的特殊注意

如果你用 Claude API（而非 claude.ai 网页）：

- API key 的调用 IP 同样被记录；
- 不要让 API key 在公网服务器上裸奔（被恶意调用 → 异常流量 → 账号风控）；
- 服务器调用 API，用 **固定的服务器 IP**，不要让 API key 走轮换代理；
- API key 泄露 = 账号风控的常见原因，定期轮换 key，设置用量告警。

## 五、网络环境快查表

```
✅ 稳定的住宅 / 移动网络出口
✅ 长期 1 个地区，不跳国家
✅ 1–2 台固定设备
✅ 保持登录态，不频繁登出
✅ API key 固定 IP 调用，设用量告警

❌ 数据中心 IP 直连
❌ 免费共享代理
❌ 一天换三个国家的节点
❌ 指纹浏览器伪装
❌ 多设备并发 + cookie 复制
```

## 小结

网络环境是防风的 **物理基础**。后面用得再合规，IP 每天乱跳也白搭。先把网络画像稳定下来，再做其他优化。
