# 01 · 账号注册合规

> 账号活不活得久，从注册那一刻就开始决定了。注册信息越"像一个真实的人"，越不容易被风控。

## 一、身份信息

### 1. 用真实身份注册

- 邮箱：用自己 **长期持有** 的邮箱（Gmail / Outlook / 自有域名邮箱均可），不要用一次性邮箱、临时邮箱。
- 姓名：与支付方式、与后续可能申诉时提交的证件 **能对得上**。Anthropic 在申诉时可能要求身份证明，姓名对不上会直接卡死。
- 手机号：如果流程要求，用本人实名的号码。

### 2. 不要批量注册

- 同一身份、同一支付卡、同一 IP 短时间内注册多个账号 = 最经典的风控触发模式。
- 个人只需要一个账号。即便有"工作 + 个人"两个场景的需求，也用不同身份、不同支付分别注册，且不要交叉使用。

## 二、支付方式

### 1. 与注册身份一致

- 信用卡 / 借记卡持卡人姓名 = 注册姓名。
- 账单地址 = 真实地址，能在账单上对上。
- 支付方式与注册信息不一致，是订阅被取消的高频原因。

### 2. 优先级

| 支付方式 | 推荐度 | 说明 |
|---------|--------|------|
| 个人信用卡 | ⭐⭐⭐⭐⭐ | 最稳，持卡人可追溯 |
| 借记卡 | ⭐⭐⭐⭐ | 稳定，注意余额充足 |
| Apple/Google Pay 绑卡 | ⭐⭐⭐⭐ |  underlying 卡仍需合规 |
| 虚拟卡 / 隐私卡 | ⭐⭐ | 部分虚拟卡 BIN 段被标记，风控更严 |
| 共享卡 / 他人卡 | ⭐ | 强烈不推荐，持卡人与注册人不一致 |

### 3. 虚拟卡的坑

虚拟卡（含部分"隐私卡"服务）不是不能用，但要注意：

- 部分 BIN 段（发卡行识别号）已被 Anthropic 风控标记，用这类卡注册支付容易直接被拒或随后取消；
- 虚拟卡余额不足导致扣款失败 → 订阅被取消 → 频繁换卡重试 = 风控信号叠加；
- 如果必须用虚拟卡，用主流发卡行、保持稳定余额、不要频繁换卡。

## 三、地区合规

### 1. Anthropic 服务地区

Anthropic 对服务地区有明确政策。注册和使用时：

- 账号注册地区、支付方式地区、实际使用地区 **三者尽量一致**；
- 如果你在 Anthropic 明确不提供服务的地区，注册和使用本身存在合规风险，本 Skill 不提供规避方案，只提示风险存在。

### 2. 不要伪装地区

- 用代理 IP 伪装成"服务地区用户" + 用真实身份注册 = 地区信息冲突，风控高发；
- 这类操作即使短期可用，长期被检测到大概率封号，且申诉无门（因为你确实在违规）。

## 四、注册后的"养号"动作

注册成功后的前 7 天是风控观察期，建议：

1. **完善账号信息**：填全个人资料，绑定可用的恢复邮箱；
2. **首次订阅用稳定支付**：不要注册当天就频繁切换订阅档位；
3. **正常使用**：每天少量、正常地对话，建立"真实用户"的行为画像；
4. **不要立刻接 API 高频调用**：新账号 + 高频 API = 自动化脚本画像。

## 小结

注册这一步的核心只有一句：**让 Anthropic 看到一个真实、可追溯、行为正常的人**。后面所有的防风技巧，都建立在这条之上。
