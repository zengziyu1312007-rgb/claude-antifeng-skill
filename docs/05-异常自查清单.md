# 05 · 异常自查清单

> 账号出现异常时，按这篇 **逐步** 排查，不要一上来就找客服。80% 的"异常"是使用习惯问题，自查能解决。

## 一、先识别：这是什么异常？

| 症状 | 可能原因 | 优先排查 |
|------|---------|---------|
| 提示 "unusual activity" / 要验证 | 网络 / 设备画像异常 | 第二节 |
| 对话突然被限流（消息额度暴跌）| 档位超用 / 脚本画像 | 第三节 |
| 登录被踢，要求重新验证 | 多设备 / session 异常 | 第四节 |
| 订阅被取消，扣款失败 | 支付问题 | 第五节 |
| 完全无法登录，账号不存在 | 封禁 | 见 `06-申诉与恢复.md` |
| API 返回 401 / key 失效 | key 被吊销 / 账号风控 | 第六节 |

## 二、网络 / 设备画像异常自查

按顺序确认：

- [ ] 最近是否换了网络环境（出差、换宽带、换代理节点）？
- [ ] 是否在新的设备上登录了账号？
- [ ] 出口 IP 是否落到了数据中心段（云厂商 IP）？
- [ ] 是否短时间内在多个地区 IP 登录过？
- [ ] 是否用了指纹浏览器 / 隐私模式 / 不熟悉的浏览器？

**修复**：

1. 回到 **平时最常用的网络 + 设备**；
2. 完成平台要求的验证（邮箱验证码、手机验证码）；
3. 之后 **保持稳定**，至少 7 天不要换环境；
4. 删除可疑的已登录设备会话（Settings → 已登录设备）。

## 三、限流 / 脚本画像自查

- [ ] 最近对话量是否远超平时？
- [ ] 是否在多个会话并发发消息？
- [ ] 是否用了脚本 / 自动化工具驱动 claude.ai 网页？
- [ ] 调用间隔是否过短（连续无间隔发送）？
- [ ] 是否集中在某一敏感领域大量提问？

**修复**：

1. 停止并发，回到单会话；
2. 用量降回档位正常范围；
3. 停用网页自动化脚本（要自动化请走 API）；
4. 多样化使用，不要在单一敏感领域挖；
5. 等待额度刷新（一般按 5 小时滚动窗口）。

## 四、会话 / 登录异常自查

- [ ] 是否同时在多台设备在线？
- [ ] 是否把 cookie / session 给了别人？
- [ ] 是否在不同设备间复制了登录态？
- [ ] 是否频繁登出登入？

**修复**：

1. 在 Settings → Sessions / 已登录设备里 **登出所有其他会话**；
2. 只在主力设备重新登录一次；
3. 修改密码（强制其他会话失效）；
4. 开启二步验证；
5. 之后不再共享 session。

## 五、支付 / 订阅异常自查

- [ ] 信用卡是否过期 / 换卡？
- [ ] 是否额度不足 / 触发银行风控？
- [ ] 账单地址是否与注册一致？
- [ ] 是否用了虚拟卡且余额不足？
- [ ] 是否反复点了"重试扣款"？

**修复**：

1. 先去银行 / 卡 App 确认状态，排除余额 / 风控；
2. 在 Anthropic Console 更新支付方式（用合规的个人卡）；
3. **一次** 重试扣款，不要疯狂点；
4. 如果订阅已被取消，重新订阅，不要在取消状态下反复操作。

## 六、API key 异常自查

- [ ] key 是否在公网仓库 / 日志里泄露过？
- [ ] 调用 IP 是否突然变化？
- [ ] 是否有异常用量飙升？
- [ ] key 是否被多人共用？

**修复**：

1. 立即在 Console **撤销** 该 key；
2. 生成新 key，只在 **固定服务器 IP** 上使用；
3. 设置用量告警（spend threshold）；
4. 排查代码仓库 / 日志 / 配置文件，清理硬编码的 key。

## 七、自查后仍异常？

- 自查 + 修复后等 24–48 小时观察；
- 仍异常 → 进入 `06-申诉与恢复.md` 走官方渠道；
- **不要** 在自查没做完时就找客服，客服一查后台发现你使用习惯有问题，反而强化风控判定。
