# 账号健康自查清单

> 建议每周跑一次。5 分钟。提前发现风险信号，比被封后申诉强 100 倍。

## 一、身份与支付

- [ ] 注册邮箱仍由本人持有且能收信
- [ ] 注册姓名与当前证件一致
- [ ] 订阅扣款卡未过期、额度充足
- [ ] 账单地址与注册地址一致
- [ ] 近 30 天无支付失败记录

## 二、网络与设备

- [ ] 出口 IP 近 7 天归属地稳定（同一地区）
- [ ] 未使用数据中心 IP / 共享免费代理
- [ ] 在用设备 ≤ 2 台
- [ ] 已登录会话列表无陌生设备
- [ ] 未在公共 / 他人设备登录过

## 三、使用习惯

- [ ] 日用量在档位正常范围（未顶格跑）
- [ ] 无多会话并发
- [ ] 无网页自动化脚本驱动 claude.ai
- [ ] API 调用有指数退避，未疯狂重试 429
- [ ] 近 7 天使用主题多样，未集中敏感领域

## 四、安全

- [ ] 已开启二步验证
- [ ] API key 无泄露（未硬编码进仓库 / 日志）
- [ ] API key 调用 IP 固定
- [ ] 已设置用量告警（spend threshold）
- [ ] 90 天内轮换过 API key（高频使用建议）

## 五、内容

- [ ] 未尝试越狱 / "解除限制"式 prompt
- [ ] 未用角色 wrapper 包装敏感内容
- [ ] Claude 输出的高风险结论（医疗/法律/金融）均经人工核实
- [ ] 未向 Claude 投喂他人 PII

## 评分

- 全勾：账号健康，继续保持。
- 1–2 项未勾：有风险点，本周内修复。
- 3 项以上未勾：高风险，立刻按 `docs/05-异常自查清单.md` 处理。
